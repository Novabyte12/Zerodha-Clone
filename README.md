# 📈 Zerodha Clone - Full Stack Trading Platform

A full-stack web application replicating key features of the Zerodha trading platform.
Built with a modular architecture consisting of a primary frontend, an interactive dashboard, and a backend API.

## 🛠️ Tech Stack & Architecture

This project is divided into three main components:

### 1. Frontend (/frontend)
* Built with **React.js**
* Serves as the primary landing page, marketing interface and user onboarding platform.

### 2. Dashboard (/dashboard)
* Built with **React.js** & **React Router**
* Provides a portfolio holdings visualizer.

### 3. Backend (/backend)
* Built with **Node.js**, **Express.js** and **MongoDB**
* RESTful API serving data to the React client applications.
